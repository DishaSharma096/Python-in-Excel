# Python-in-Excel Project
📌 Project Overview

This project focuses on analyzing sales data to clean , filter and provide good analysis of data by python code and AI. Identify and remove duplicate records.
- Handle missing values.
- Rename and clean column names.
- Filter data based on specific conditions.
- Perform basic data transformations.
- Export cleaned data into a CSV file. 

🎯 Project Objectives

TO Clean Excel file data with the help of python for making ease of data analysis and manual work with the AI automation. 

🛠️ Tools & Technologies
 
 Python : For data clean and filter
 Pandas
 VS Code
 MS Excel : To Getting data file
 ChatGpt(AI) : For python code 


💡 Business Value

This python code demonstrates how raw sales data can be transformed into clean data by using python and Generative AI. It supports performance monitoring, helps identify growth opportunities, and enables better data-driven decision-making.
